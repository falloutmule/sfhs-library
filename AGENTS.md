# SFHS Library

This directory is a separate launcher project. The parent SNC game remains untouched.

- Product constraints are recorded in docs/PRODUCT-CONSTRAINTS.md.
- Edit src/, tools/, public/, tests/. Root index.html is generated by npm.cmd run build.
- No runtime CDN dependencies, bundled credentials, or telemetry.
- Untrusted applications must remain in opaque-origin sandbox frames. Never add allow-same-origin.
- Preserve original payload bytes and deterministic executable capsules separately.
- Never upgrade compatibility, save, offline, or backup claims without the matching proof.
- Generated proofs belong under ignored test-results/.
- Run build, build:check, focused tests and browser smoke after meaningful changes.
- Phone acceptance and deployed commit verification are separate release gates.
